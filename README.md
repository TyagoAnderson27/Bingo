# Bingo UTD 🎲

Um aplicativo de jogo de Bingo moderno desenvolvido em React com Vite.

## 🚀 Funcionalidades
- **Globo 3D:** Bolinhas tridimensionais integradas com React Three Fiber.
- **Sorteio Automático:** Configuração para sorteio com intervalo de 10 segundos.
- **Validação de Vitória:** Sistema automatizado que confere a cartela ao gritar Bingo.
